Overview

System Purge is a personal project exploring advanced vehicle physics and combat mechanics in Unreal Engine 5. The goal is to create an arcade-style driving experience that feels responsive and satisfying while maintaining a robust networked architecture for multiplayer support.

This project serves as a technical showcase for my C++ programming skills, physics system implementation, and understanding of UE5's replication framework.

Technical Implementation

Custom Physics Model

Implemented a custom drift physics system using slip angle calculations and tire friction curves to achieve arcade-style handling within a realistic physics engine.

Network Replication

Server-authoritative movement with client-side prediction and lag compensation. Designed for smooth gameplay even under high latency conditions.

Modular Weapon System

Data-driven weapon system using Data Assets, allowing easy iteration on weapon stats, projectile behaviors, and visual effects without code changes.

Code Highlight

The core drift mechanics implementation using slip angle calculations:

VehicleMovement.cpp 
void ACombatVehicle::CalculateDriftForces(float DeltaTime)
{
    // Get local velocity relative to actor rotation
    FVector LocalVel = GetActorTransform().InverseTransformVector(Velocity);

    // Calculate slip angle based on lateral velocity
    float SlipAngle = FMath::Atan2(LocalVel.Y, LocalVel.X);

    // Apply counter-force based on friction curve
    float GripFactor = TireFrictionCurve->GetFloatValue(SlipAngle);
    AddForce(GetActorRightVector() * -LocalVel.Y * GripFactor);
}
