Mechanical Rigger

A Blender add-on that automates hard-surface rigging by converting Mesh Hierarchy to Bones. Includes smart detection for Pistons and Hinges, plus a one-click export pipeline for Unreal Engine.

Type

Open Source Plugin

Context

Workflow Automation

The Problem

Rigging mechanical assets (robots, weapons) manually is tedious. Animators need to align bones precisely to pivots, setup standard constraints for Pistons and Hinges, and manage complex hierarchies. Exporting a clean skeletal mesh to Unreal Engine often requires destructive "Apply Transform" steps that break the rig.

The Solution

The Mechanical Rigger plugin reads the Outliner Hierarchy to auto-generate the Armature. It detects specific naming conventions (e.g., Piston_01_Cyl) to automatically rig complex mechanisms with correct constraints. Finally, it includes a non-destructive Batch Exporter that bakes the rig for Game Engines.

Key Features

Hierarchy-Based Rigging

Converts Parent-Child relationships in the Outliner directly into Bone Chains. No need to draw bones manually; just organize your meshes and click Build.

Auto-Piston Setup

Detects Piston_ID_Cyl and _Rod collections. automatically generating the necessary bones and Damped Track constraints for hydraulic cylinders.

Smart Mirroring

Tag collections with _Mirrored to generate symmetric rigs (Left/Right). Uses "Linked Duplicates" for the right side, so modeling changes propagate instantly.

Game Engine Export

Bakes the complex Control Rig into a clean, single-mesh Skeletal Mesh. Corrects unit scale and axis orientation for Unreal Engine integration.

Implementation

Regex-based validation ensures the user follows naming conventions for automatic Piston and Mirroring setup:

def validate_selection(context):
    """Checks selected objects for Naming Conventions (Pistons)."""
    
    # Regex to find Piston_ID_Type in Collection Name
    piston_pattern = re.compile(r"Piston_(.+?)_(Cyl|Rod)")
    pistons = {}

    for obj in context.selected_objects:
        if not obj.users_collection: continue
        col = obj.users_collection[0]
        
        # Remove _Mirrored suffix for check
        clean_col_name = col.name.replace("_Mirrored", "")
        match = piston_pattern.match(clean_col_name)

        if match:
            pid = match.group(1)   # ID
            ptype = match.group(2) # Cyl or Rod
            
            if pid not in pistons:
                pistons[pid] = set()
            pistons[pid].add(ptype)
